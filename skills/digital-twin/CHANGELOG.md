## [0.1.0] - 2026-04-16

### Added

- 新增正式的 `CHANGELOG.md`，用于记录 skill 的结构演进与知识边界调整。
- 为主文件 `SKILL.md` 补充任务分流规则、输出契约、边界条件、禁止事项与维护规则。
- 为 `architecture.md`、`deployment.md`、`frontend.md`、`lessons.md`、`vendors.md` 补充适用场景、默认立场、固定输出结构与风险触发器。

### Changed

- 将 `digital-twin` 从偏“人物设定 / 技术画像”的文档，升级为偏“数字员工 / 技术决策代理”的可执行技能。
- 将支持文档从经验陈列改造成面向回答生成的知识库，使其可直接支撑架构、部署、前端、排障与厂商对接类任务。
- 收敛技能边界，明确该 skill 只处理技术决策与工程知识，不承担职业包装或非技术文案职责。

### Removed

- 从 `SKILL.md` 中移除简历包装、自我介绍包装等非技术任务分流。
- 从 `digital-twin` 目录中剥离简历草稿，职业材料改由独立文档处理，不在本 skill 范围内。
