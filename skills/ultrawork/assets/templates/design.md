# 设计契约（Design Contract）—— 边界 / IO / 主链路 / 支线链路 / 状态机

> **在写任何代码前落地**，连同 spec + design + plan + tasks 一起交 **人工闸①** 审核（用户逐 MF 过支线表 + 状态机非法流转）。这份定义"系统到底怎么跑"。
> 铁律：**每条主链路必须按分层清单覆盖支线，每个接口必须有 IO 契约，每个有生命周期的实体必须有状态机**。
> 漏定义 = Analyze 门禁判 **CRITICAL 硬挡 / HIGH 默认挡（可放行并记录）**，不许进实现（见 references/analyze-gate.md，两文口径一致）。
> 每条主/支链路都要可测 → 直接映射到 tasks.md 的 acceptance 与 tester 用例。

## 1. 系统边界（Boundary Contract）
- **系统边界**：本系统负责什么 / 明确不负责什么（in / out of scope，逐条）。
- **模块边界**：每个模块职责 + 模块间接口（谁调谁、同步/异步、耦合方向）。
- **信任边界**：外部输入的进入点在哪、在哪做鉴权/授权/校验/限流/幂等（画出信任边界线）。
- **外部依赖边界**：第三方 / 厂商 / 其它仓库接口（命中 human-gate 卡点3，交付须人工确认）。

## 2. 输入输出契约（I/O Contract，逐接口/API）
| 接口 / API | 输入（结构 / 类型 / 必填 / 校验规则） | 正常输出（结构 / 状态码） | 错误形态（错误码 / 信息 / 何时发生） | 幂等 / 超时 / 限流 |
|---|---|---|---|---|

> **IO 归属**：接口级 IO 细节（结构/状态码/错误码）以本节为**权威**；spec.md 的 FR 只表"需要哪些语义字段 + 验收意图"，不与本节重复冲突（Analyze 会对账两者）。
> **非 HTTP 域**：错误形态列可填 HTTP 码，也可填 MQTT 错误主题 / 协议异常帧 / 死信 / 返回码（按域，见 §4）。

### 非请求驱动的主链路（事件 / 消息 / 定时，按需）
IoT / MQTT / EMS 等域的主链路未必是"请求→响应"。此类补一套骨架：**触发源**（topic / 定时 / 设备帧）、**幂等键**、**消费位点 / 重试 / 死信**、**顺序与背压**、**后置状态**、可测验收。

## 7. 数据契约 / 事务边界 / 审计事件（后台/业务系统必审）
- **落库字段**：哪些字段持久化、唯一约束、索引。

- **审计与可观测事件**：金额/DDL/契约类操作的审计轨迹（谁 / 何时 / 改了什么）+ 关键路径埋点 / 指标。

## 8. 安全与合规设计（对外 SaaS / 等保·ISO·SOC2 —— 门禁见 references/enterprise-gates.md）
- **威胁建模（STRIDE）**：对每条主链路 / 信任边界，列 欺骗 / 篡改 / 否认 / 信息泄露 / 拒绝服务 / 权限提升 的威胁 + 缓解。
- **数据分级**：标出 敏感 / PII / 鉴别数据字段 → 决定加密与审计范围。
- **访问控制（RBAC）**：角色 × 资源 × 操作 权限矩阵；最小权限；细粒度（用户级主体 × 表/记录级客体）；**对外 SaaS：tenant / resource / record 级授权 + IDOR/越权测试用例**；**管理员三权分立（系统/安全/审计管理员分权，等保 8.1.4.2d）**；登录失败锁定 + 会话超时 + 口令复杂度（8.1.4.1）；无默认口令 / 共享账户。
- **加密 + 密钥管理**：传输 TLS；敏感数据存储加密；完整性 MAC / 签名；鉴别 ≥ 双因素**且其中一种须密码技术（等保 8.1.4.1d）**；**KMS + 密钥轮换 + 访问分离 + 吊销**。
- **审计事件目录**：每用户安全操作（登录/鉴权/授权变更/数据访问/导出/配置/金额/DDL）写审计日志，字段含 时间/用户/类型/成败，**防篡改 + 审计进程防未授权中断（8.1.4.3d）+ 留存 ≥ 6 月**。
- **数据生命周期（含 PII）**：分级 → 保留期 → 安全删除 / 释放前剩余信息清除（等保 8.1.4.6）→ PII 删除权 / 最小化（8.1.4.11、ISO A.8.10、SOC2 CC6.5）。
- **可靠性**：日志/指标/追踪埋点、SLO、回滚/DR 方案（回滚须验证）。
- **安全测试**：SAST + DAST/渗透（ISO A.8.29）+ SCA/SBOM（供应链）——门禁见 `references/enterprise-gates.md`（G1–G11）。
