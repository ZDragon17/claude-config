# Markdown Rules

## 结构
- 每个文档一个 H1 标题
- 标题层级递增，不跳级
- 使用目录 (TOC) 帮助导航
- 段落之间空一行

## 格式
- 代码块指定语言
- 行内代码用反引号
- 强调用 **粗体**，不用全大写
- 列表保持一致的风格

## 链接
- 使用相对路径引用项目内文档
- 外部链接检查有效性
- 图片添加 alt 文本

## 代码示例
- 提供可运行的示例
- 包含预期输出
- 解释关键步骤

## README 必备
- 项目描述
- 安装步骤
- 快速开始示例
- 贡献指南链接
- 许可证

## Changelog
- 遵循 Keep a Changelog 格式
- 按版本号降序排列
- 分类: Added, Changed, Fixed, Removed
